# Критерии оценки и пункты защиты

Источник: гайд участника AI Challenge. Формальной таблицы баллов в гайде нет; ниже — то, что жюри прямо называет. Статусы: ⬜ не начато, 🟨 в работе, ✅ закрыто.

## Что оценивают

| ID | Требование | Цитата из кейса | Чем закрываем | Статус |
|---|---|---|---|---|
| J1 | Оригинальность идеи | «Мы оцениваем не количество AI-функций и не сложность интерфейса, а оригинальность идеи, реальную ценность для пользователя и потенциал создания нового бизнеса» | | ⬜ |
| J2 | Реальная ценность для пользователя | (там же) | | ⬜ |
| J3 | Потенциал нового бизнеса | (там же) | | ⬜ |
| J4 | Новая ценность, а не упаковка контента | «Создают новую пользовательскую ценность, а не просто меняют упаковку существующего контента» | | ⬜ |
| J5 | Самостоятельный рост | «Имеют потенциал для самостоятельного роста аудитории и бизнеса» | | ⬜ |
| J6 | Преимущества NMH | «Используют реальные или потенциально доступные преимущества News Media Holding» | | ⬜ |
| J7 | AI создаёт основную ценность | «Предпочтение получат решения, где AI создаёт основную ценность продукта, а не просто пересказывает тексты или генерирует картинки» | | ⬜ |

## Пункты защиты

| ID | Требование | Цитата из кейса | Чем закрываем | Статус |
|---|---|---|---|---|
| D1 | Проблема и пользователь | «Кто ваш клиент, как он решает задачу сегодня и почему существующие решения его не устраивают?» | | ⬜ |
| D2 | Идея и уникальность | «Как работает продукт, что в нём принципиально нового и какие существующие российские решения вы изучили?» | | ⬜ |
| D3 | Роль AI | «Какие конкретные задачи выполняет искусственный интеллект и почему он существенно улучшает продукт?» | | ⬜ |
| D4 | Преимущество NMH | «Какие активы холдинга необходимы для запуска или развития проекта?» | | ⬜ |
| D5 | Бизнес-модель | «Кто платит, за что и как продукт может масштабироваться?» | | ⬜ |
| D6 | Ключевые метрики | «По каким показателям мы поймём, что продукт востребован и способен зарабатывать?» | | ⬜ |
