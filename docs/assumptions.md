# Допущения и открытые вопросы

## Допущения

- Компании и цифры в демо — вымышленные; ИНН демо-компании не совпадает с настоящей организацией.
- LLM в демо — через OpenAI-совместимый API; в CI и тестах — только мок.
- Проверка компании — через сервис подсказок по ЕГРЮЛ или кэш реального ответа.
- Оплата в прототипе — заглушка: механика заморозки показана без реальных денег.
- Модератор работает через админку Django.
- Цены и доли (претензия 1 490 ₽, 70% проверяющему, 10% со сделки) — ориентиры из `docs/product.md`, задаются настройками.
- Нормы права в библиотеке до проверки юристами показываются с пометкой «не проверено юристом».
- Корпус для «Шансов в суде» собирается вручную по одной категории: у баз судебных решений нет открытого API. Без корпуса блок скрыт.
