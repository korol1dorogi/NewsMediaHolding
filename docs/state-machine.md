# Состояния обращения

Переходы проверяются на бэкенде; недопустимый переход — ошибка 409. Описание продукта — `docs/product.md`.

## Общая часть

| Из состояния | Событие | В состояние | Кто вызывает | Условие |
|---|---|---|---|---|
| — | Пользователь написал | `draft` | Пользователь | — |
| `draft` | Не хватает данных | `clarifying` | AI | Есть вопросы или нужны документы |
| `clarifying` | Пользователь ответил | `draft` | Пользователь | — |
| `draft` | Карточка собрана | `card_ready` | AI | Обязательные поля заполнены или помечены «не найдено» |
| `card_ready` | Пользователь подтвердил | `card_confirmed` | Пользователь | — |
| `card_ready` | Пользователь поправил | `card_ready` | Пользователь | — |
| `card_confirmed` | Выбран путь | `self_guided` / `claim_draft` / `in_pool` | Пользователь | Путь доступен для статуса компании |
| любое активное | Пользователь закрыл | `closed` | Пользователь | — |

## Реши сам

| Из состояния | Событие | В состояние | Кто вызывает | Условие |
|---|---|---|---|---|
| `self_guided` | Результат отмечен | `closed` | Пользователь | — |
| `self_guided` | Перешёл к другому пути | `claim_draft` / `in_pool` | Пользователь | — |

## Официальный запрос

| Из состояния | Событие | В состояние | Кто вызывает | Условие |
|---|---|---|---|---|
| `claim_draft` | Данные подтверждены и претензия оплачена | `claim_in_review` | Пользователь | ФИО, адрес, реквизиты подтверждены; деньги заморожены |
| `claim_in_review` | Юрист взял в работу | `claim_in_review` | Юрист | Претензия закрепляется за юристом; не проверил за 4 часа — возврат в общую очередь |
| `claim_in_review` | Юрист подтвердил | `claim_approved` | Юрист | — |
| `claim_in_review` | Юрист исправил | `claim_edited` | Юрист | Есть комментарий |
| `claim_edited` | Пользователь принял правки | `claim_approved` | Пользователь | — |
| `claim_edited` | Пользователь не согласен | `claim_in_review` | Пользователь | Есть комментарий |
| `claim_approved` | Деньги разморожены | `claim_approved` | Сервис | Комиссия юристу-проверяющему |
| `claim_approved` | Претензию признали ошибочной | `claim_in_review` | Второй юрист / модератор | Бесплатная перепроверка другим юристом; первому — без комиссии, минус в рейтинге, запрет брать это дело |
| `claim_approved` | Пользователь отметил отправку | `awaiting_response` | Пользователь | Пользователь отправил сам; дата отправки сохранена |
| `awaiting_response` | Компания ответила, вопрос решён | `resolved` | Пользователь / компания | — |
| `awaiting_response` | Срок вышел или отказ | `no_response` | Сервис / пользователь | — |
| `no_response` | К специалисту | `in_pool` | Пользователь | — |
| `resolved` | Комиссия оплачена или возврата не было | `closed` | Пользователь / сервис | — |

## Специалист

| Из состояния | Событие | В состояние | Кто вызывает | Условие |
|---|---|---|---|---|
| `in_pool` | Пришло предложение | `has_offers` | Юрист | Карточка обезличена и прошла проверку; проверявший претензию юрист может предложить услуги, только если его претензию не признали ошибочной и компания отказала или не ответила |
| `in_pool` | Срок вышел, предложений нет | `no_offers` | Сервис | — |
| `has_offers` | Пользователь принял предложение и оплатил | `offer_accepted` | Пользователь | Деньги заморожены; персональные данные открываются юристу |
| `offer_accepted` | Юрист начал | `in_progress` | Юрист | — |
| `in_progress` | Работа сдана | `work_submitted` | Специалист | Приложен результат |
| `work_submitted` | Пользователь подтвердил или вышел срок | `completed` | Пользователь / сервис | — |
| `work_submitted` | Спор | `disputed` | Пользователь | — |
| `disputed` | Модератор решил | `completed` / `in_pool` | Модератор | — |
| `completed` | Деньги разморожены и выведены юристу | `closed` | Сервис | За вычетом комиссии платформы |
| `disputed` | Работа не выполнена | `closed` | Модератор | Деньги возвращены пользователю |
| `no_offers` | Повторно в пул / другой путь | `in_pool` / `claim_draft` | Пользователь | — |
