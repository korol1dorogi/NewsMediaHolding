# Требования кейса

Источник: «AI Challenge / Гайд участника», NMH × МГТУ им. Н.Э. Баумана, 13–15 ноября 2026 (`AI_Хакатон.pdf`, у лида). Статусы: ⬜ не начато, 🟨 в работе, ✅ закрыто.

| ID | Требование | Цитата из кейса | Чем закрываем | Статус |
|---|---|---|---|---|
| C1 | Новый цифровой продукт для пользователя и новый источник дохода | «придумать новый цифровой продукт, который превратит эти возможности в полезный или интересный пользовательский опыт и новый источник дохода для холдинга» | | ⬜ |
| C2 | Не способ читать новости | «мы не ищем ещё один способ читать или смотреть новости» | | ⬜ |
| C3 | Новая причина прийти для тех, кто не читает СМИ холдинга | «новую причину, по которой человек будет обращаться к продукту News Media Holding, даже если сегодня он не читает наши СМИ» | | ⬜ |
| C4 | Начать с реальной проблемы | «Найдите реальную потребность аудитории, которую существующие цифровые продукты решают недостаточно хорошо» | | ⬜ |
| C5 | Конкретный сегмент аудитории | «платёжеспособные жители крупных городов 25–45 лет… Найдите конкретный сегмент с понятной потребностью» | | ⬜ |
| C6 | Объяснить монетизацию | «Кто будет платить и за что конкретно? … Какие ключевые затраты… При каких условиях он может стать прибыльным?» | | ⬜ |
| C7 | Использовать преимущества NMH | «Если такой же продукт может запустить любая команда без участия NMH и ничего не потерять в ценности, подумайте, достаточно ли вы использовали возможности холдинга» | | ⬜ |
| C8 | AI — двигатель продукта | «Если убрать из продукта AI и он будет работать так же, значит, AI там не нужен» | | ⬜ |
| C9 | Конкретный пользователь | «Назовите конкретного пользователя и проблему, которую он сегодня решает» | | ⬜ |
| C10 | Честно назвать, на чём построено | «Нельзя выдавать чужой продукт или готовый проект за свою разработку: честно назовите всё, на чём построено ваше решение» | README → «Архитектура», `docs/decisions.md` | 🟨 |
| C11 | Уникальность для российского рынка | «Новый продукт должен быть уникальным для российского рынка» | | ⬜ |
| C12 | Каждый объясняет решение и поведение при ошибке AI | «Каждый в команде должен за минуту рассказать, как работает ваше решение и что случится, если AI ошибётся» | | ⬜ |
| C13 | Работающий прототип: один законченный сценарий | «К финалу нужен работающий прототип: один законченный сценарий, от потребности пользователя до результата… за 3–5 минут» | `docs/mvp.md` | 🟨 |
| C14 | Ответ на главный вопрос | «Почему через год человек будет регулярно пользоваться вашим продуктом, хотя сегодня даже не знает, что он ему нужен?» | | ⬜ |
| C15 | Не только лента, пересказ, чат-бот или дайджест | «персонализированная новостная лента, AI-пересказчик, чат-бот с новостями, обычный дайджест и перенос существующего продукта на новую платформу сами по себе не считаются новыми продуктовыми идеями» | | ⬜ |
