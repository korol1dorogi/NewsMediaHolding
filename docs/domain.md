# Предметная область

Полное описание продукта — `docs/product.md`. Термины в коде, контракте и интерфейсе используются только в этих значениях.

| Термин | В коде | Что значит |
|---|---|---|
| Обращение | `Case` | Случай пользователя от первого сообщения до закрытия. Проходит статусы из `docs/state-machine.md` |
| Сообщение | `Message` | Реплика в диалоге: от пользователя или от AI |
| Документ | `Document` | Файл, который загрузил пользователь: чек, договор, скриншот |
| Карточка случая | `Fact` (набор) | Факты из обращения: кто, кому, сколько, когда, что обещали, что произошло. У каждого факта — цитата-источник. Пользователь подтверждает карточку |
| Цитата-источник | `Fact.source_quote` | Дословный фрагмент сообщения или документа, из которого взят факт. Код проверяет, что цитата действительно есть в источнике |
| Проверка компании | `CompanyCheck` | Статус компании в реестре юрлиц: действует, ликвидируется, банкротится |
| Шансы в суде | — | Статистика по похожим делам: сколько дел, доля решённых в пользу потребителя, средняя доля взысканного. С размером выборки и ссылками; при K < 10 не показывается |
| Путь | `Case.path` | Что выбрал пользователь: «Реши сам», «Официальный запрос», «Обращение к специалисту» |
| Реши сам | `self_guided` | Рекомендации, сроки, список документов и куда подать; пользователь действует сам |
| Официальный запрос | `claim` | Платная досудебная претензия от имени пользователя, проверенная юристом. Отправляет пользователь сам |
| Претензия | `Claim`, `ClaimVersion` | Досудебное требование от имени потребителя. Черновик готовит AI, утверждает юрист, финальный текст подтверждает пользователь |
| Юрист | роль `lawyer` | Юрист или юрфирма на подписке: проверяет претензии из общей очереди и берёт дела из пула |
| Очередь проверки | — | Общая очередь претензий. Юрист берёт претензию сам; не проверил за 4 часа — она возвращается в очередь |
| Ошибочная претензия | `Claim.faulty` | Утверждённая претензия с юридической ошибкой. Подтверждает второй юрист или модератор; пользователь получает бесплатную перепроверку |
| Пул | `PoolCard` | Список обезличенных карточек, доступный юристам |
| Обезличенная карточка | `PoolCard` | Карточка без персональных данных и документов: категория, город, сумма диапазоном, компания, что уже сделано |
| Предложение | `Offer` | Что юрист сделает, срок и цена. После согласия и оплаты юрист получает данные пользователя |
| Заморозка денег | `Hold` | Оплата пользователя, удержанная платформой до принятия работы. В прототипе — заглушка без реальных денег |
| Внутренний рейтинг | `LawyerProfile.rating` | Непубличная оценка юриста. Влияет на внутреннюю проверку и место предложения в списке у пользователя |
| Групповое дело | — | Однотипные требования к одной компании у одного юриста; от 20 человек возможен групповой иск |
| Страница ответа | — | Публичная страница по ссылке из претензии, где компания отвечает бесплатно и без регистрации |
| Сигнал редакции | `Signal` | Сообщение журналистам о массовом или значимом случае, без персональных данных |
| Модератор | роль `moderator` | Проверяет карточки перед пулом, разбирает споры и жалобы |
| Комиссия с возврата | — | 10% с возвращённых денег, не больше 5 000 ₽; только в пути «Обращение к специалисту» |
