# Предметная область

| Термин | Что значит |
|---|---|
| Обращение | Сообщение человека о том, что его обманули или нарушили его права: текст, голосовое, фото, скриншоты |
| Карточка случая | Факты, извлечённые из обращения: кто, кому, сколько, когда, что обещали, что произошло. У каждого факта — цитата-источник. Человек подтверждает карточку |
| Проверка компании | Статус компании в реестре юрлиц: действует, ликвидируется, банкротится |
| Шансы в суде | Статистика по похожим делам из открытых баз решений: сколько дел, доля решённых в пользу потребителя, средняя доля взысканного. С размером выборки и ссылками |
| Исход | Путь, который выбирает человек: «Сделай сам», «Претензия и ответ компании», «Специалист» |
| Претензия | Досудебное требование от имени потребителя. Имеет юридическую силу |
| Запрос сервиса | Деловое письмо от сервиса компании со ссылкой на страницу ответа. Юридической силы не имеет |
| Страница ответа | Где компания бесплатно и без регистрации отвечает на обращение |
| Группа | Похожие обращения к одной компании. От 20 человек возможен групповой иск |
| Сигнал редакции | Черновик для журналистов о массовом или значимом случае |
| Специалист | Проверенный юрист на подписке, получающий подготовленные обращения |

Подробное описание продукта — в питче команды (вне репозитория).
