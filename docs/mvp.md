# MVP для защиты

Цель — один законченный сценарий за 3–5 минут: от сообщения пользователя до результата (C13, D7).

## Сценарий демо

Аня оплатила онлайн-курс за 68 000 ₽, школа три недели не возвращает деньги. Компания и цифры — вымышленные, демо-данные помечены.

1. Аня пишет в сервис и прикладывает чек и скриншот переписки.
2. Карточка: школа, ИНН, сумма, даты; у каждого факта — цитата из источника. Аня подтверждает.
3. Проверка компании: действует. «Шансы в суде» по похожим делам. Три пути со сроком и ценой.
4. Аня выбирает «Претензия и ответ компании»: претензия от её имени и запрос сервиса со ссылкой на страницу ответа.
5. «Вы не один»: похожие обращения на ту же школу.
6. Школа отвечает на странице ответа, ответ появляется в карточке.
7. Экран редакции: сигнал о массовом случае.

## Блоки

| № | Блок | В демо | Задачи |
|---|---|---|---|
| 1 | Приём: текст и фото → карточка с цитатой-источником | По-настоящему; голос — если успеем | |
| 2 | Проверка компании по ИНН | По-настоящему или кэш реального ответа | |
| 3 | Пути, генерация претензии и запроса компании | По-настоящему: LLM и шаблоны | |
| 4 | «Вы не один»: склейка похожих обращений | Демо-данные с пометкой | |
| 5 | Страница ответа компании, ответ в карточке | Заглушка по сценарию | |
| 6 | Экран редакции | По-настоящему: генерация по данным группы | |
| 7 | «Шансы в суде» | Корпус по одной категории, собран вручную | |
| 8 | «Проверь до оплаты» | Тот же экран, что в блоке 2 | |

## Вне MVP

Кабинет юриста и подписка, комиссия с возврата, рейтинг исполнителей, предупреждения по городу, бот в MAX.
