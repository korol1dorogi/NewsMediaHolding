## Проект

AI Challenge · News Media Holding × МГТУ им. Н.Э. Баумана · 13–15 ноября 2026.

**Продукт в одной фразе.** Человек пишет в сервис холдинга о том, что его обманули или нарушили его права, и за несколько минут получает не молчание, а результат.

**Путь пользователя.**
1. Вход: текст, голосовое, фото чека или скриншот.
2. Карточка: AI извлекает факты с цитатой-источником, человек подтверждает.
3. Проверка компании по реестру.
4. «Шансы в суде» и выбор пути: сделай сам, претензия и ответ компании, специалист.
5. Результат и трекер.

Подробности — в `docs/domain.md`, `docs/mvp.md`, `docs/case.md`.

## Как работаем

1. **Одна задача — одна ветка — один PR.** Ветка: `<ID>-<кратко>`, например `B3-intake-card`. Задачи берём из `docs/tasks.md`, владельца и статус обновляем в том же PR.
2. **Сначала контракт.** Новый или изменённый эндпоинт начинается с правки `docs/openapi.yaml`. Затем `npm run gen:api` во `frontend/`. Фронт до готовности бэка работает с моком: `docker compose --profile mock up -d mock`.
3. **Маленькие коммиты на английском** в формате `type: summary` (`feat`, `fix`, `test`, `docs`, `chore`, `refactor`).
4. **Перед PR прогоняем проверки локально** и вставляем вывод в PR: бэк — `ruff check`, `ruff format --check`, `pytest`, `makemigrations --check`; фронт — `npm run lint`, `typecheck`, `test`, `build`.
5. **Мерж в `main` — только лид**, только через PR с зелёным CI.

## Правила кода

- **Доступ к данным.** Любой объект пользователя отдаётся только владельцу. Чужой объект — **404**, не 403. На каждый такой эндпоинт — тест «чужой получает 404».
- **Аутентификация.** Сессии Django + CSRF, один origin через Caddy. CORS не включаем.
- **Окружение.** Новая переменная — сразу в `.env.example` с заглушкой и в `backend/config/settings.py` с умолчанием через `env_*`. Пустое значение не должно ронять приложение.
- **LLM.** По умолчанию `LLM_PROVIDER=mock`: детерминированный ответ, без сети и ключей. Тесты и CI работают только на моке.
- **Модель не принимает юридических решений.** Факты — с цитатой-источником; сроки и суммы считает код; нормы права — из проверенной библиотеки, а не генерируются.
- **Секреты и реальные данные** в репозиторий не кладём. Персональные данные в логах не пишем.
- **Зависимости** сверх базового стека — только после согласия лида.

## Карточка задачи

Копируйте в `docs/tasks.md` под сводной таблицей.

```markdown
### <ID>. <Название>

- **Зачем:** какое требование кейса или шаг пути пользователя закрывает (ссылка на docs/case.md или docs/mvp.md)
- **Что сделать:**
  - …
- **Контракт:** какие эндпоинты добавляются или меняются в docs/openapi.yaml (или «не меняется»)
- **Готово, когда:**
  - [ ] …
  - [ ] тесты, включая «чужой получает 404», если есть данные пользователя
  - [ ] e2e или newman, если меняется сценарий
- **Зависит от:** ID задач
- **Владелец:** имя
- **Оценка:** часы
```
